# 锅气 · 中餐调味模拟器

一个单页网页：按秒模拟锅温、水分、油量，以及每种调料的出香、挥发、焦糊，看下料顺序和火候怎样改变一道中餐的味道。

在线使用：打开 GitHub Pages 地址（见仓库 About），或直接下载 `index.html` 用浏览器打开。

## 三个模式

- **改经典菜**：19 道经典菜（宫保鸡丁、鱼香肉丝、麻婆豆腐、回锅肉、红烧肉、水煮鱼……）的标准做法作底，改调料种类、用量、顺序、火力和时间，看味道雷达、相似度、锅温曲线、口感和师傅提醒。
- **从零下厨**：空锅开始，实时开火下料（1×/5×/20× 倍速），看锅里每样东西的出香、焦化、熟度；出锅评菜并找出最像的经典菜。锅里只放香料时，给出复合香味、匹配香型和适配的菜。
- **调香料**：35 种香料，选研磨、焙香、油炸或炖卤，模拟复合香气的前中后调、提取曲线与苦涩，匹配五香粉、十三香、红卤、火锅料等 15 种经典香型，推荐适合的菜和用量；配好的料可加入调料架在另两个模式里用。

## 模型说明

数值是对家常烹饪经验的近似，用来看趋势、比较做法，不是精确的化学计算。

## 开发

源码在 `src/`，修改后运行 `python3 build.py` 生成单文件 `index.html`。
