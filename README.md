# 锅气 · 中餐调味模拟器

从零拆解烹饪：按秒模拟锅温、水分、油量，以及每种调料的出香、挥发、焦糊和食材的熟度、口感，再按自己的口味自动改良，生成自己的菜谱。

在线使用：开启 GitHub Pages 后访问 `https://mingxintan-coder.github.io/Cook/（注意 C 大写）`。菜谱库数据在 `recipes.json`，需要通过网址打开（直接双击本地文件时读不到菜谱库，其余功能可用）。

## 模块

- **菜谱工坊**：19 道经典菜 + 村驴、隋坡、老东北美食、鞑厨高寒的 1000 多道家常菜（由文字配方自动转换，附原文和来源链接，并标出可行性高/中/低；估计的用量标“估”）。逐步修改调料、用量、顺序、火力、时长，支持“烧开为止 / 油温到 X°C / 收汁到浓”和“捞出香料”。
- **按口味改良**：设定咸甜酸辣麻鲜等的增减、肉更嫩/更软烂、菜更脆/更软，以及少盐、少油、控糖、不吃辣、不用酒、不用味精、家里没有某样调料；程序试算后改用量、换料、加料、调火候，逐条说明改了什么。
- **AI 设计菜**：选主料、味型、做法和口感，程序在模拟器里试几十个版本，挑出完美度最高的做法并解释关键步骤。在 Claude 里打开时还可以“请 Claude 主厨设计”：Claude 构思菜谱、在模拟器里试做几次再修改（GitHub 版没有这个按钮）。
- **菜谱卡**：把步骤写成能照着做的菜谱（克数 + 勺数、火力、时长、油温提示），可按主料重量换算、复制文字、存进“我的菜谱”。
- **从零下厨**：实时灶台，空锅开始下料，出锅评菜并找出最像的经典菜；只放香料时给出复合香味和适配的菜。
- **调香料**：35 种香料，模拟复合香气的前中后调、提取曲线与苦涩，匹配 15 种经典香型与适合的菜。
- **我的菜谱**：保存在本机浏览器，可导出导入。

数值是对家常烹饪经验的近似，用来看趋势、比较做法，不是精确的化学计算。菜单配方来自网友整理的文字版，自动转换难免与原视频有出入。

## 开发

- 源码在 `src/`，修改后运行 `python3 build.py` 生成 `index.html`。
- 菜谱库：`node tools/extract.js` 从 menu 仓库的 `index.html` 提取配方，再运行 `node tools/import_menu.js menu_dishes.json recipes.json` 转换。
